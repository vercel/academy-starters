# AGENTS.md

## This is a Vercel Academy starter

This project is the starter for the **Slack Agents on Vercel with the AI SDK** course on Vercel Academy: https://vercel.com/academy/slack-agents

The course builds on this code one lesson at a time. If the person you're helping is working through the course:

- **Install the course skill** for lesson-by-lesson guidance, progress checks, and troubleshooting:

  ```sh
  npx skills add vercel-labs/academy-skills --skill slack-agents -y
  ```

- **Read the lessons as markdown.** The course index, with every lesson URL in its frontmatter, is at https://vercel.com/academy/slack-agents.md, and each lesson is at `https://vercel.com/academy/slack-agents/<lesson-slug>.md`.
