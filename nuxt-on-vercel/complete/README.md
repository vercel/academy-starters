# Hot Springs Finder — Complete

The finished app for the **Nuxt on Vercel** course on [Vercel Academy](https://vercel.com/academy/nuxt-on-vercel).

```bash
pnpm install
cp .env.example .env   # add your GitHub OAuth credentials and a session password
pnpm dev
```

Then open http://localhost:3000. The starter lives on the [`main`](../../tree/main) branch.
