# Agent-Friendly APIs: starter

> This is the starter for **[Agent-Friendly APIs](https://vercel.com/academy/agent-friendly-apis)** on Vercel Academy. Start at [lesson 1.1, Project Setup](https://vercel.com/academy/agent-friendly-apis/setup-project).

## Run it locally

### Prerequisites

- Node.js 20.9 or later, the minimum for Next.js 16 (`package.json` doesn't pin a version)
- pnpm, to match the `pnpm-lock.yaml` in this folder
- A Vercel account for the deploy steps in the course

### Environment variables

None. The feedback API reads its sample data from `data/feedback.json`.

### Commands

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 to see the app.
