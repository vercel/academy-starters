# Agent-Friendly APIs: complete

> This is the finished app for **[Agent-Friendly APIs](https://vercel.com/academy/agent-friendly-apis)** on Vercel Academy. Use it to check your work as you go through the course.

## Run it locally

### Prerequisites

- Node.js 20.9 or later, the minimum for Next.js 16 (`package.json` doesn't pin a version)
- pnpm, to match the `pnpm-lock.yaml` in this folder
- A Vercel account for the deploy steps in the course

### Environment variables

None. The feedback API reads its sample data from `data/feedback.json`.

### Commands

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 to see the app.
