# AGENTS.md

## This is a Vercel Academy starter

This project is the starter for the **Python on Vercel** course on Vercel Academy: https://vercel.com/academy/python-on-vercel

The course builds on this code one lesson at a time. If the person you're helping is working through the course:

- **Install the course skill** for lesson-by-lesson guidance, progress checks, and troubleshooting:

  ```sh
  npx skills add vercel-labs/academy-skills --skill python-on-vercel -y
  ```

- **Read the lessons as markdown.** The course index, with every lesson URL in its frontmatter, is at https://vercel.com/academy/python-on-vercel.md, and each lesson is at `https://vercel.com/academy/python-on-vercel/<lesson-slug>.md`.
- **The finished code** for comparison is in the course's `complete` folder: https://github.com/vercel/academy-starters/tree/main/python-on-vercel/complete
