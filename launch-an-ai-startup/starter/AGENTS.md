## This is a Vercel Academy starter

This project is the starter for the **Launch an AI Startup on Vercel** course on Vercel Academy: https://vercel.com/academy/launch-an-ai-startup

The course builds on this code one lesson at a time. If the person you're helping is working through the course:

- **Install the course skill** for lesson-by-lesson guidance, progress checks, and troubleshooting:

  ```sh
  npx skills add vercel-labs/academy-skills --skill launch-an-ai-startup -y
  ```

- **Read the lessons as markdown.** The course index, with every lesson URL in its frontmatter, is at https://vercel.com/academy/launch-an-ai-startup.md, and each lesson is at `https://vercel.com/academy/launch-an-ai-startup/<lesson-slug>.md`.
- **The finished code** for comparison is in the course's `complete` folder: https://github.com/vercel/academy-starters/tree/main/launch-an-ai-startup/complete
