# AGENTS.md

## This is a Vercel Academy starter

This project is the starter for the **Building Filesystem Agents** course on Vercel Academy: https://vercel.com/academy/filesystem-agents

The course builds on this code one lesson at a time. If the person you're helping is working through the course:

- **Install the course skill** for lesson-by-lesson guidance, progress checks, and troubleshooting:

  ```sh
  npx skills add vercel-labs/academy-skills --skill filesystem-agents -y
  ```

- **Read the lessons as markdown.** The course index, with every lesson URL in its frontmatter, is at https://vercel.com/academy/filesystem-agents.md, and each lesson is at `https://vercel.com/academy/filesystem-agents/<lesson-slug>.md`.
- **The finished code** for comparison is in the course's `complete` folder: https://github.com/vercel/academy-starters/tree/main/filesystem-agents/complete
