# AGENTS.md

## This is a Vercel Academy starter

This project is the starter for the **Launch a Subscription Store with Vercel and Stripe** course on Vercel Academy: https://vercel.com/academy/subscription-store

The course builds on this code one lesson at a time. If the person you're helping is working through the course:

- **Install the course skill** for lesson-by-lesson guidance, progress checks, and troubleshooting:

  ```sh
  npx skills add vercel-labs/academy-skills --skill subscription-store -y
  ```

- **Read the lessons as markdown.** The course index, with every lesson URL in its frontmatter, is at https://vercel.com/academy/subscription-store.md, and each lesson is at `https://vercel.com/academy/subscription-store/<lesson-slug>.md`.
