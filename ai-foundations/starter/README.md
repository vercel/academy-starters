# AI Foundations — Starter

A minimal scaffold for the AI Foundations course. You'll create scripts here as you work through the lessons.

## Setup

```bash
pnpm install
cp .env.example .env
# Add your AI Gateway key to .env
```

## Running scripts

Each lesson will have you create a script in `scripts/`. To run it:

```bash
pnpm script scripts/01-first-call.ts
```

That's it. No app to start, no server to deploy. You're going to learn how AI works by running small scripts and reading the output.
